# ERICK & ANDREA — EL VÍNCULO AZUL

Proyecto Android Studio en Kotlin. Primera versión jugable del RPG romántico/fantástico.

## Abrir y generar APK

1. Descomprime este ZIP.
2. Abre **Android Studio**.
3. Selecciona **Open** y elige la carpeta `ErickAndreaRPG` (la que contiene `settings.gradle.kts`).
4. Espera a que Android Studio termine la sincronización de Gradle. Si solicita instalar SDK/Build Tools, acepta la instalación.
5. En la barra superior selecciona la variante **debug**.
6. Ve a **Build → Generate App Bundles or APKs → Generate APKs**.
7. El APK quedará en:
   `app/build/outputs/apk/debug/app-debug.apk`

También puedes usar el botón de ejecución ▶ para instalarlo directamente en un teléfono conectado por USB con Depuración USB activada.

## Requisitos

- Android Studio reciente (con soporte para AGP 8.7.x).
- JDK 17 (Android Studio normalmente lo incluye).
- Android SDK 35.
- No hace falta configurar un servidor ni una base de datos.

## Contenido de esta versión

- Erick y Andrea como protagonistas.
- Sistema de nivel, XP, vida, oro y pociones.
- Sistema de Vínculo de 0 a 100.
- Exploración del Valle, Bosque, Ciudad y Ruinas.
- Combate por turnos.
- Habilidades de Erick, magia de Andrea y ataque combinado.
- Enemigos y recompensas.
- Historia inicial de Aetheria.
